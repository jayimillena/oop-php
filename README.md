# Object-Oriented PHP Tutorial Series

A comprehensive, beginner-to-intermediate guide to Object-Oriented Programming (OOP) in PHP, based on the tutorial series by **The Net Ninja (Shaun Pelling)**.

---

## 📌 Project Overview

This repository acts as a companion guide and course syllabus for **The Net Ninja's Object Oriented PHP Tutorial Series**. The series covers core OOP concepts in PHP from fundamental building blocks like classes and objects to real-world applications such as building a form validation class.

## 🛠️ Prerequisites & Setup

To follow along with these lessons, ensure you have:

* **PHP 7.0+** or **PHP 8.x** installed locally.
* A local development server environment (e.g., [XAMPP](https://www.apachefriends.org/), [MAMP](https://www.mamp.info/), or PHP's built-in server).
* A code editor such as **VS Code**.

### Running PHP's Built-in Server

```bash
php -S localhost:8000
```
